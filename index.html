About Minesweeper
Minesweeper
Version 3.1 (Web Recreation)

A fan-made browser recreation of the classic Microsoft Minesweeper (WINMINE.EXE) from the Windows 3.1 era, intended to preserve the original look, feel, and behavior.

How to Play

The object of Minesweeper is to find all the mines without uncovering any of them.

Left-click a covered square to uncover it. The number on a square tells how many mines touch it.

Right-click a square to plant a flag if you believe it holds a mine. With Marks turned on, right-click again to change it to a question mark, and once more to clear it.

If a number has exactly that many flags around it, press both mouse buttons (or the middle button) on the number to uncover the remaining squares around it.

The timer starts on your first left click. The game is won when every square without a mine has been uncovered. F2 starts a new game.
